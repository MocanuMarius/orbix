# Smaller openings and self-contained skill chapters

Starting gifts now offer five inexpensive entry skills and fifteen single relics. The draw remains two choices from twenty, stable for the same expedition seed. The skill options are Proximity (60), Luminance (45), Momentum (30), Collector Search (30), and Resonant Harvest (40), using base Stored Spark prices.

The runtime offer filter enforces a base skill price ceiling of 60. It also checks actual prerequisites, learned skills, exclusions and companion compatibility, so a cheap leaf cannot bypass an expensive parent. Dream, Glide Regeneration, Spark Vessel, Fourth Beat, Long Flash, Spark Sense and Cache Handling are no longer free opening shortcuts. Players can purchase them normally. Quiet Cinder and Prism Vessel are also removed from the opening relic pool; the catalogue no longer bundles multiple relics into one opening gift. Conditional relics remain for distinct collection strategies, without claiming mathematically identical value.

Existing chosen gifts are retained. The rule applies to new gift choices. No purchased skill or relic has been globally nerfed.

Chapter classification now has one shared source used by both the model and the book. Every live prerequisite stays in the child's chapter and, for companions, the same companion role. Dream no longer requires Luminance, and Storage no longer requires Flight. Deep Cache follows its Storage chain. Collector Cache Handling follows Collector Search. Internal paths, prerequisite order, alternatives and their prices remain.

The model normalizes foreign-only dependencies to a chapter's own entry skill; the entry itself is independent. Valid local requirements are retained. Checks cover missing/retired references, cycles and buying every live skill using only its own chapter.

Nineteen focused opening, catalogue, pricing and skill-book checks pass, including all twenty gifts, persistence, price/prerequisite rejection and chapter-local purchases. Existing tests that expected free Dream or Dream's former cross-chapter requirement were updated to the new intended behavior.
